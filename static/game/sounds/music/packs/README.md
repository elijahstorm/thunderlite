# Adaptive music packs

Each directory is one composition delivered as independent stems: same length,
same tempo, same key, mixed to sum cleanly in any combination. A match picks one
pack from its seed and holds it (packs differ in tempo and key, so mixing or
crossfading between them would clash). Registered in
`src/lib/Audio/musicPacks.ts`; every layer must exist in both `.ogg` and `.mp3`,
carrying the same audio, because format is negotiated per browser at runtime.

`layer1` is the foundation, up in every mood except silent. The rest are extras
that variation raises and drops freely.

| pack    | loop   | layers | phrases    | source                                                    |
| ------- | ------ | ------ | ---------- | --------------------------------------------------------- |
| `pack1` | 60.00s | 3      | 4 x 15.00s | Blips.fm, `MP3 Files (1).zip` + `Ogg Files (1).zip`       |
| `pack2` | 66.98s | 3      | 5 x 13.40s | Blips.fm, `MP3 Files.zip` + `Ogg Files.zip`               |
| `pack3` | 69.57s | 3      | 5 x 13.91s | Blips.fm, `MP3 Files (2).zip` + `Ogg Files (2).zip`       |
| `demo`  | 96.00s | 6      | 6 x 16.00s | generated by `scripts/audio/gen-demo-layers.sh`, dev only |

Blips ships every pack with the same generic `Track_1_Layer_N` filenames, so the
ids above are positional (ordered by loop length). Rename the id and its
directory together once each pack has a title worth showing a player.

Verified on import: layers within a pack agree to within 3ms, and each layer's
`.ogg` and `.mp3` agree to within 60ms. `tests/Audio/musicPacks.unit.test.ts`
re-checks both on every run.
